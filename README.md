# Workspace Hub

A modern, offline-first personal workspace dashboard for organizing files, PDFs, links, bookmarks, and notes in an intuitive multi-workspace environment.

## Features

- **Multi-Workspace Support**: Create distinct workspaces (e.g. Courses, Research, Personal) with individual data isolation.
- **Minimalist Item Cards**: Sleek horizontal pills with custom color-coded indicators for links, files, notes, and folders.
- **Folder Management & Explorer**: Nested folder hierarchy, drag-and-drop file organization, breadcrumbs navigation, and empty status indicators.
- **Right-Click Context Menu**: Instant access to Info & History, Copy Link/Path, Download, Rename, Move, and Delete.
- **Offline & Local**: Runs locally with a lightweight Express backend and vanilla web frontend with local offline Lucide icons.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or newer)

### Installation & Run

1. Clone or download this repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   - On Windows: Double-click `start.bat` or run:
     ```bash
     npm start
     ```
4. Open [http://localhost:3000](http://localhost:3000) in your web browser.
